# Note-style article reader UI kit

A long-form reader inspired by note.com (the platform Tsunagu publishes on), styled with the brand's tokens.

## Components
- `ReaderHeader` — top bar with brand, nav, search, avatar.
- `Cover` — full-bleed thread-field hero image for an article.
- `Byline` — author line with スキ (like) and 保存 (save) toggles.
- `ArticleBody` — typographic body with lead, headings, blockquote, lists.
- `Divider` — the brand thread divider used between sections.
- `Related` — two-up related-articles grid.
- `Pill` — generic pill button (used in byline actions).

Open `index.html` for the composed reader with interactive like/save toggles.
