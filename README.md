# tsunagu-project181.com

つなぐProject の公式サイト。静的 HTML / CSS / 軽量 React。GitHub Pages でホスティング。

## 構成
- `index.html` — トップページ
- `home.css` / `colors_and_type.css` — スタイル
- `assets/` — ロゴ・カバー画像
- `note_feed/` — note記事リスト（デモデータ）
- `CNAME` — 独自ドメイン設定（GitHub Pages 用）

## デプロイ
GitHub Pages 設定で `main` ブランチのルートを公開。CNAME により `tsunagu-project181.com` で配信。
